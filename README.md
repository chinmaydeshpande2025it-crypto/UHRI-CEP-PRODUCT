# UHRI-CEP-PRODUCT
**UHRI** is an AI landslide early warning system that fuses static terrain data (XGBoost) with real-time rainfall/sensor trends (Bi-LSTM) into one explainable risk score, delivered via a dashboard and an offline-first app with SMS fallback — so alerts still reach people when the network doesn't. Prototype live at uhricommand.netlify.app.
